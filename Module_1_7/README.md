
Вхідні дані: напруга через фоторезистор, напруга через терморезистор
Вихідні дані: температура(Цельсій), освітленість(Люкс)

Спосіб розрахунку: https://emb-hardware-lib-a9b74a.pages.beetroot.academy/components/thermistors/ , *знайти для освітленості.*
Спосіб представлення: Екран, LED, Serial(через вбудований USB)

Плата: STM32F401CCU6
Сенсори: терморезистор, фоторезистор
Виводи: 128*64 екран, білий лед для освітленості, червоний лед для температури, Serial

Опис:
Плата кожні 200мс знімає показники з резисторів і розраховує значення відповідних величин. \
Отримані значення виводяться на екран та у Serial. Якщо значення перевищують сконфігуровані пороги - загоряється відповідний лед

Вивід значень на екран:
Розмір екрану: 128х64
Формат: 
```
 -99 С
--------
99e-9 lx
```

Розмір шрифта: 11x18
Температура: цельсій, діапазон [-99;999] + 1 символ для `C`
Освітленість: люкс, діапазон [99*10^-9;999*10^9], використовуючи `E notation` для зменшення діапазону [Source](https://en.wikipedia.org/wiki/Lux)


Потенційні покращення: додати покажчик часу, додати звуковий сигнал
