# three-led-blink

Простий проект на базі ESP32-S3, який по черзі вмикає червоний, синій та зелений світлодіоди

## Плата

- `esp32-s3-devkitc-1-n16r8v`
- Середовище PlatformIO: `esp32-s3-devkitc-1-n16r8v`

## Підключені до плати присторої

- Червоний світлодіод підключено до GPIO `15`
- Синій світлодіод підключено до GPIO `16`
- Зелений світлодіод підключено до GPIO `17`

## Робота

Код вмикає та вимикає червоний, синій і зелений світлодіоди у заданій послідовності, створюючи ефект схожий на гірлянду.
